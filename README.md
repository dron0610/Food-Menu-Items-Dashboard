# 🍔 Food Menu Items – Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing nutritional information of different food menu items to gain meaningful insights into their nutritional content.

The project uses **Excel, Python, SQL, and Power BI** to clean, process, analyze, and visualize food menu data through interactive dashboards.

## 🎯 Project Objectives

- Analyze nutritional values of different food menu items.
- Understand calorie distribution across food categories.
- Compare nutritional components such as fats, carbohydrates, protein, and other nutrients.
- Identify food items with higher and lower nutritional values.
- Present meaningful insights through interactive Power BI dashboards.

## 🛠️ Tools & Technologies

| Technology | Purpose |
|---|---|
| Microsoft Excel | Data exploration and initial cleaning |
| Python | Data cleaning and preprocessing |
| SQL | Data storage and querying |
| Power BI | Data visualization and dashboard creation |
| HTML, CSS, JavaScript | Website interface for accessing the dashboard |

## 🔄 Project Workflow

1. **Data Collection:** Collected food menu items and their nutritional information.
2. **Data Cleaning:** Used Excel and Python to clean and preprocess the dataset.
3. **Database Management:** Imported the processed data into SQL for structured storage and querying.
4. **Data Analysis:** Explored nutritional information and identified useful patterns.
5. **Dashboard Development:** Created interactive dashboards in Power BI to visualize nutritional insights.
6. **Web Integration:** Developed a website interface using HTML, CSS, and JavaScript to access the dashboards.

## 📊 Dashboard Features

- Nutritional analysis of food menu items.
- Calorie comparison and distribution.
- Analysis of fats, proteins, carbohydrates, and other nutrients.
- Interactive charts and visualizations.
- Easy comparison of nutritional values across menu items.
